# Smart-Campus-Assistant
A Python-based Smart Campus Assistant developed collaboratively by four team members using Git and GitHub. It provides classroom search, department information, campus facilities and contact details.
# Smart Campus Assistant

## Project Overview
Smart Campus Assistant is a Python-based application designed to help students access important campus information through a simple menu-driven interface.

## Features
1. Classroom Information – Search for classroom details.
2. Department Information – View available departments.
3. Campus Facilities – Find locations of campus facilities.
4. Campus Contacts – View important campus contact information.

## Technologies Used
- Python
- Visual Studio Code
- Git and GitHub

## How to Run

1. Install Python.
2. Clone the repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python main.py
```

5. Select the required option from the menu.
